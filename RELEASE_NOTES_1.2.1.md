# Aurora Downloader v1.2.1 (Build 77)

## Bug Fixes
* **Mini player is now the default for picture-in-picture**: the player's PIP button minimizes the video straight to the in-app floating mini-player instead of leaving the app to the system picture-in-picture window.
* **Mini player video restart**: a video that ended in the mini-player no longer gets stuck on the last frame — pressing play restarts it from the beginning.
