## Why translate the app name — evidence (2026-08-12)

- Google Play Console Help, "App discovery and ranking": the app title is
  explicitly one of the metadata signals used to match search queries
  ("metadata (for example, title, description, category) ... are used to
  determine which apps best address the user's query"). Search results are
  "heavily influenced by relevance to the user's query".
- appscreens.com "Why Localization Matters" (compiled case studies):
  Distimo +128% downloads from native-language support; Coin Splash +101%
  downloads from localized metadata (name included); Headspace +40% search
  installs in non-English markets; Koo (official Google Play case) +15%
  organic installs in non-English countries; Make App Magazine +767% from
  metadata-only localization (extreme case). Practical planning range cited:
  +15% to +40% for strong-fit markets.
- ~58% of Google Play discovery comes from search (ASO benchmarks), and only
  2-2.5% of visitors interact with the description "Read more" — so the app
  name + short description + screenshots carry almost all of the visible
  listing weight. The name translation is higher-leverage than the full
  description.
- Reddit (r/reactnative, "Should I Localize My App Title & Subtitle for
  Better ASO?"): top comment — "Absolutely worth testing! It can make a huge
  difference in visibility and rankings. Many users search using their native
  language ... If possible, run A/B tests ... even small lifts in conversion
  can add up globally." Unanimous yes, with the caveat to test.
- For THIS app: "Download Manager" is the category keyword in English; the
  translated name ("Менеджер загрузок", "下载管理器", ...) captures the same
  high-intent keyword in each language's search.
- Honest limits: localization only pays in markets that already have demand
  (check Play Console Statistics per country); a bad translation can damage
  trust; brand "Aurora" is never translated. The launcher label on-device is
  NOT part of store search — leave it as the English brand (just fix the
  manifest label from "Aurora Downloader" to "Aurora Download Manager").
