# Aurora Downloader v1.1.1 (Build 69)

## New Features
* **Range Selection**: You can now long-press items in the download queue to quickly select a massive range of downloads at once (similar to Shift-clicking on a PC).
* **Batch Duplicate Handling**: Sniffer batch downloads now prompt you with a unified "Apply to all duplicates" option when encountering existing files.

## Bug Fixes
* Fixed missing and incorrect French localization strings across multiple dialogs and pages.
* Fixed analyzer warnings on `queue_page.dart`.
* Updated Duplicate Choice enumerations to clarify Replace vs Create New.
