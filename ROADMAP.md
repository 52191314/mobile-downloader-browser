# Aurora Roadmap Ledger

This ledger keeps planned feature lanes visible while current work focuses on
Capture IQ.

1. Reliability: foreground download service, persistent notifications,
   background survival, and pause/resume from notifications.
2. Share/Open-With intake: Android intent filters for URLs, magnets,
   `.torrent` files, and shared links.
3. Capture IQ: likely-media filtering, grouping, HLS labels, and recommended
   selection.
4. Per-site browser profiles: site-specific adblock, desktop mode,
   cookies/session preferences, and download defaults.
5. Download rules/automation: auto-rename, route by file type/site,
   Wi-Fi/charging/schedule rules.
6. History/library manager: unified search across downloads, favorites,
   history, saved pages, tags, and bulk actions.
7. Better HLS output: optional FFmpeg/remux pass for MP4 output after
   licensing and APK-size review.
8. S23U build/update flow: version/build metadata, ABI marker, build date,
   OAuth client, and easier install/update script.
